# Transparência Cidadã

Painel acadêmico em Next.js para visualização de dados públicos da Câmara dos Deputados.

## Funcionalidades

- Listagem de deputados com nome, partido, UF e foto.
- Filtros por nome, estado e partido.
- Cards com total de deputados exibidos, total de despesas e média de despesas.
- Gráfico de barras para comparação de despesas por deputado.
- Gráfico de linha para evolução mensal das despesas.
- Tema claro/escuro com persistência no navegador.
- Estados de carregamento, erro e dados vazios.

## Dados

Fonte: API de Dados Abertos da Câmara dos Deputados.

As chamadas externas são feitas por API routes internas do Next.js.
